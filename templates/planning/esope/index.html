Comment ça marche
  1. Paramétrage : fonctions, postes, horaires et nombre de bénévoles par poste.
  2. Bénévoles ESOPE : fonctions possibles et jours de disponibilité de chacun ({{ nb_benevoles }} bénévoles marqués ESOPE).
  3. Planning modèle : la semaine type, avec les personnes qui viennent toutes les semaines ou une semaine sur deux.
  4. Générer le mois : les créneaux sont créés et les bénévoles du modèle placés.
  5. Planning : retouches, absences, horaires partiels, impression.
  6. Envoi aux bénévoles : chacun reçoit ses créneaux et un lien personnel pour confirmer ou annuler ; les réponses arrivent par mail à la responsable.
Les jours de fermeture (fériés, congés) sont à saisir avant de générer le mois : jours de fermeture. Toutes les actions sont tracées dans l'historique.
