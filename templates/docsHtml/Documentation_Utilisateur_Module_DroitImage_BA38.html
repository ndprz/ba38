Aide – Droit à l’image

Cet écran centralise, pour chaque bénévole, le statut de son autorisation “droit à l’image” ainsi que le lien vers le document signé correspondant.

Les statuts possibles

  • Accord Total : la personne autorise l’utilisation de son image (accord donné avec signature).

  • Refus : la personne refuse l’utilisation de son image.

  • (case vide) : le statut n’a pas encore été renseigné.

Ces statuts sont ceux affichés sous forme de pastille de couleur (🟢 accord total, 🔴 refus, ⚪ non renseigné) sur la liste des bénévoles. Il n’y a que deux réponses possibles : accord total ou refus.

Modifier les statuts

Chaque ligne du tableau correspond à un bénévole et peut être modifiée directement :

  • Acceptation : liste déroulante pour choisir le statut (Accord Total ou Refus).

  • Lien PDF : champ texte pour renseigner le lien (Drive) vers le document signé.

  • Signature : lorsque l’accord a été signé depuis le téléphone (module « Photo bénévole »), un lien « ✍️ Voir » s’affiche avec la date de signature ; il ouvre l’image de la signature.

Une fois les modifications faites sur une ou plusieurs lignes, cliquer sur “💾 Enregistrer” en bas du tableau pour les valider toutes en une seule fois.

Saisir le droit à l’image depuis un téléphone

Le module « Photo bénévole » (mobile) permet de recueillir l’accord directement sur le terrain : le bénévole signe avec le doigt (accord total) ou refuse. Le statut de cette page est alors mis à jour automatiquement.

Filtrer et rechercher

  • Le menu déroulant en haut de page permet de n’afficher que les bénévoles ayant un statut donné (ou “Tous les accords”).

  • La barre de recherche filtre instantanément le tableau par nom, prénom ou statut.

Export Excel

Le bouton “📊 Export Excel” télécharge un fichier Excel de la liste, en tenant compte du filtre de statut actuellement sélectionné.

Mode lecture seule

Si le compte utilisé n’a pas les droits de modification sur ce module, un bandeau “🔒 Mode lecture seule” s’affiche et les champs du tableau ne sont pas modifiables.
