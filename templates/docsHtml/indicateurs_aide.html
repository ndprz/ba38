GUIDE D’UTILISATION DE L’APPLICATION

1. Objectif du module

Le module Indicateurs ÉTAT permet de créer et gérer des campagnes de collecte d’indicateurs auprès des associations, d’envoyer des demandes par email avec un PDF pré-rempli, de suivre les réponses, de relancer les associations non-répondantes, de vérifier que les mails sont réellement partis, et d’analyser les résultats.

2. Création d’une campagne

Accès : Menu → Indicateurs ÉTAT → Nouvelle campagne

Étapes :

  • Choisir la période (trimestre ou année)

  • Définir une date limite

  • Importer le fichier CSV exporté de l’AMS (voir Préambule)

Cas particulier : campagne existante

Si une campagne existe déjà pour la période choisie, une fenêtre propose deux choix :

  • Voir la campagne existante (sans rien modifier)

  • Mettre à jour depuis un nouveau fichier CSV (écrase les statuts déjà importés, il faut re-uploader le CSV même si c’est le même fichier)

3. Écran Résultats

C’est l’écran central pour suivre une campagne. On y trouve :

  • Des pastilles cliquables (Validés / Non reçus / À revoir / Absents AMS / Total) qui filtrent le tableau en un clic

  • Un champ Date limite modifiable directement sur cet écran (plus besoin de recharger le CSV juste pour changer la date)

  • Un bandeau qui indique si un envoi réel a déjà eu lieu, quand, par qui, et combien de mails sont partis avec succès — ou s’il n’y a eu qu’un envoi en Mode TEST

  • Pour chaque association : si son mail est parti, quand, et son statut Mailjet (envoyé / ouvert / rebond / bloqué / spam)

  • Un bouton pour exclure ponctuellement une association d’un envoi (relance individuelle non désirée par exemple)

Statuts possibles :

  • Validé

  • Non reçu

  • A revoir

  • Absent AMS (association présente dans notre base mais absente de l’AMS, c’est-à-dire non active dans VIF — vérifier la fiche partenaire VIF, onglet coordonnées)

4. Envoi des demandes et relances

Bouton 📤 Envoyer mails sur l’écran Résultats. Un email est envoyé à chaque association dont le statut est « Non reçu » (et qui n’est pas exclue), avec en pièce jointe un PDF pré-rempli (nom de l’association, code VIF, période, date limite).

Mode TEST : la case est cochée par défaut par sécurité — dans ce mode, seuls 2 mails partent, tous les deux vers une adresse de test interne, jamais vers les vraies associations. Pour un envoi réel, il faut décocher explicitement cette case ; une fenêtre de confirmation s’affiche alors avant l’envoi pour éviter toute erreur.

L’envoi se fait maintenant en arrière-plan : la page répond immédiatement avec un message “envoi lancé en arrière-plan”, puis les mails partent progressivement pendant quelques minutes selon le nombre d’associations. Actualiser la page Résultats après quelques instants pour voir le bandeau et les statuts se mettre à jour.

Relance : possible plusieurs fois — l’envoi ne cible que les associations encore « Non reçu » (et non exclues) au moment du clic, donc les associations déjà « Validé » ou « A revoir » ne reçoivent pas de mail supplémentaire.

5. Vérifier qu’un envoi s’est bien passé

Deux outils sur l’écran Résultats, en cas de doute sur la remise d’un mail :

  • 🔄 Vérifier statut Mailjet : interroge Mailjet pour connaître le statut réel de chaque mail envoyé (envoyé, ouvert, rebond, bloqué, spam…) et l’affiche par association.

  • 🔁 Renvoyer via Gmail (par association, en cas de rebond) : certaines boîtes mail (notamment Hotmail/Outlook et mail.ru) rejettent parfois temporairement les mails envoyés par Mailjet. Ce bouton permet de renvoyer le même mail, avec le même PDF, directement depuis la messagerie officielle ba380@banquealimentaire.org — une copie reste alors visible dans les mails envoyés de cette boîte.

6. Gestion des textes de mails

Bouton ✉️ Textes mails. Les emails envoyés aux associations sont basés sur des modèles paramétrables, contenant des variables remplacées automatiquement (nom de l’association, période, date limite).

Lors de la création ou modification d’un modèle, un champ Catégorie permet d’indiquer s’il s’agit d’un modèle pour les indicateurs trimestriels, annuels, ou de facturation. Ce champ est indispensable : un modèle sans catégorie n’apparaîtra dans aucun écran d’envoi. Il est possible de créer plusieurs modèles pour une même catégorie (par exemple une demande initiale et un texte de relance différent), et de choisir lequel utiliser au moment de l’envoi.

7. Gestion des templates PDF

Les templates PDF sont des formulaires créés sous Adobe Acrobat Pro par le service informatique, placés dans le dossier /templates/pdf, qui permettent le pré-remplissage automatique des champs (nom de l’association, code VIF, période, date limite…).

Toute demande de création ou modification de template PDF doit être adressée au service informatique avec la liste des champs attendus.

8. Points d’attention

  • Toujours vérifier que la case Mode TEST est dans l’état souhaité avant de cliquer sur Envoyer mails.

  • Après un envoi réel, laisser quelques minutes puis vérifier le bandeau de l’écran Résultats et, si besoin, cliquer sur Vérifier statut Mailjet pour confirmer la bonne remise.

  • En cas de rebond répété sur une adresse Hotmail/Outlook/mail.ru, utiliser le renvoi via Gmail plutôt que de multiplier les tentatives via l’envoi groupé.
