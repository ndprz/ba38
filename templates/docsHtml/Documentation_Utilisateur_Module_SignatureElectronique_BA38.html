Documentation Utilisateur — Module Signature Électronique BA38

Objectif

Faire signer électroniquement n’importe quel document PDF (bon de commande, courrier, attestation…) directement depuis BA38, sans passer par un logiciel externe. Deux cas d’usage :

  • Vous signez vous-même le document.
  • Vous envoyez le document à quelqu’un d’autre (fournisseur, partenaire, collègue) pour qu’il le signe.

La signature est réalisée via LibreSign, un outil de signature électronique. Un email est envoyé au signataire avec un lien pour accéder au document et le signer en ligne.

  1. Accéder au module

Menu → Signature électronique.

  1. Envoyer un document pour signature
  • Choisir le fichier PDF à faire signer (uniquement des PDF).
  • Donner un nom au document (par exemple “Bon de commande - Fournisseur X”). Si ce champ est laissé vide, le nom du fichier est utilisé.
  • Choisir le signataire :
    • “Je signe moi-même” : vous recevrez l’email de signature à votre propre adresse.
    • “Envoyer à quelqu’un d’autre” : indiquer le nom et l’email du destinataire.
  • Positionner la signature : un aperçu du document s’affiche automatiquement après avoir choisi le fichier. Cliquez à l’endroit de la page où le pavé de signature doit apparaître. Un rectangle bleu confirme l’emplacement choisi. Si le document comporte plusieurs pages, utilisez les boutons “Page précédente” / “Page suivante” pour naviguer avant de cliquer.
  • Cliquer sur “Envoyer pour signature via LibreSign”.

Le document apparaît alors dans la liste “Mes demandes de signature” avec le statut “Envoyée pour signature”.

  1. Suivre une demande

Le signataire reçoit un email avec un lien vers le document. Une fois qu’il a signé (ou si vous voulez vérifier l’avancement), cliquez sur le bouton “🔄 Vérifier le statut” sur la ligne correspondante. Le statut passe alors à “Signée” si la signature a bien été effectuée.

Les statuts possibles :

  • Envoyée pour signature : en attente du signataire.
  • Signée : le document a été signé, le PDF signé est disponible au téléchargement.
  • Erreur : l’envoi vers LibreSign a échoué (voir le message affiché au moment de l’envoi).
  1. Télécharger les documents

Deux boutons sont disponibles sur chaque ligne dès que les fichiers existent :

  • “📄 Original” : le PDF tel qu’envoyé, avant signature.
  • “📥 Signé” : le PDF signé, disponible une fois le statut passé à “Signée”.
  1. Supprimer une demande

Le bouton “🗑️ Supprimer” retire définitivement la demande de la liste : la ligne est effacée de la base et les fichiers associés (original et signé) sont supprimés du serveur. Une double confirmation est demandée avant suppression. Cette action est irréversible.

  1. Points d’attention
  • Seuls les fichiers PDF sont acceptés.
  • La position du pavé de signature doit être choisie avant l’envoi ; sans clic sur l’aperçu, le bouton d’envoi reste désactivé.
  • Le texte apposé par LibreSign sur le document signé peut actuellement afficher les accents de façon incorrecte (par exemple “Sign??” au lieu de “Signé”) ; ceci n’affecte pas la validité de la signature, un correctif est prévu.
  • Chaque utilisateur ne voit que ses propres demandes de signature.
