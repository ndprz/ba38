Aide – Analyse d’un fichier PARSOL2L

Cet écran analyse un export PARSOL2L annuel (fichier texte issu de VIF) pour calculer, pour chaque association (identifiée par son code VIF), le nombre total de bénéficiaires livrés sur l’année.

Analyser un fichier

Sélectionner le fichier PARSOL2L (.txt) puis cliquer sur “🔍 Analyser”. L’outil parcourt le fichier, additionne le nombre de bénéficiaires de chaque livraison par code VIF, puis recherche chaque code VIF dans la base des associations.

Résultat

Un tableau liste, pour chaque code VIF trouvé dans le fichier :

  • Code VIF et Compte comptable de l’association correspondante.

  • Association : le nom de l’association, si le code VIF a été retrouvé en base.

  • Bénéficiaires : le total de bénéficiaires cumulé sur l’année pour ce code VIF.

  • Trouvé : “Oui” si le code VIF correspond à une association existante en base, “Non” sinon.

Un encart en bas de page résume le nombre total de codes VIF traités, et le nombre de codes VIF non retrouvés dans la base (à corriger côté fiche association si nécessaire — code VIF manquant ou erroné).

Export Excel

Le bouton “📥 Export Excel” télécharge le tableau de résultats au format Excel.
