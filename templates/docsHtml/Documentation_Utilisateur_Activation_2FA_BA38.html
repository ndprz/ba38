Activer la double authentification (2FA) sur mon compte

Pourquoi activer le 2FA ?

Le 2FA (double authentification) ajoute un code à usage unique à votre mot de passe habituel. Même si quelqu’un devinait ou volait votre mot de passe, il ne pourrait pas se connecter à votre place sans avoir aussi votre téléphone ou votre messagerie.

C’est rapide à mettre en place (2 minutes par SMS ou par email, 5 minutes avec une application) et simple à utiliser : un code à recopier quand vous vous connectez depuis un nouvel appareil.

Choisissez comment recevoir votre code

Après votre mot de passe, un écran vous propose trois moyens. Choisissez celui qui vous convient — vous ne le faites qu’une seule fois :

  • Par SMS — vous saisissez votre numéro de portable et recevez un code par SMS. Le plus simple : rien à installer.

  • Par email — le code est envoyé à l’adresse email de votre compte. Pratique si vous n’avez pas de portable, à condition de pouvoir ouvrir votre messagerie au moment de vous connecter.

  • Application d’authentification — un code qui change toutes les 30 secondes s’affiche dans une application sur votre téléphone (voir « Option application » plus bas).

Activer par SMS ou par email

1. Allez sur la page de connexion habituelle de BA38.

2. Cochez la case « Activer la double authentification (première fois seulement) », sous le mot de passe.

3. Saisissez votre email et votre mot de passe, puis connectez-vous.

4. Sur l’écran qui s’affiche, choisissez « Par SMS » ou « Par email ».

5. Par SMS : saisissez votre numéro de portable (06… ou 07…), puis cliquez sur « Recevoir le code ». Votre numéro n’est enregistré qu’une fois le code recopié : une faute de frappe ne peut donc pas bloquer votre compte.

6. Recopiez le code à 6 chiffres reçu, puis cliquez sur « Activer la double authentification ». Le SMS arrive en général en quelques secondes, parfois jusqu’à une minute ; pour un email, pensez à regarder les courriers indésirables. Le code est valable 10 minutes.

7. Vous êtes connecté. Laissez cochée la case « Ne plus me demander de code sur cet appareil pendant 6 jours » si vous utilisez toujours le même ordinateur.

Ensuite, à chaque connexion depuis un nouvel appareil (ou au bout de 6 jours), un écran vous propose de recevoir un code par SMS ou par email : cliquez sur le moyen de votre choix, puis recopiez le code.

Remarque : si un administrateur a déjà imposé la 2FA sur votre compte, la case est inutile — le code vous est demandé automatiquement (par SMS si un numéro a été enregistré pour vous, sinon par email). Pour un compte partagé (secrétariat, permanence), c’est l’administrateur qui enregistre les numéros.

Option application — Étape 1 : installer une application d’authentification sur votre téléphone

Avant de l’activer sur BA38, installez une application gratuite sur votre téléphone (depuis l’App Store sur iPhone, ou le Play Store sur Android).

Applications recommandées, gratuites et sans abonnement :

  • Google Authenticator — la plus simple, aucun compte à créer, il suffit de scanner un QR code.

  • Microsoft Authenticator — équivalente à Google Authenticator, avec en plus une sauvegarde optionnelle liée à un compte Microsoft.

  • 2FAS Auth — alternative gratuite et open source, avec sauvegarde optionnelle.

Toutes ces applications font exactement la même chose : elles affichent un code à 6 chiffres qui change toutes les 30 secondes. Le choix de l’application n’a pas d’importance, du moment qu’elle est installée avant l’étape 2.

Remarque : certaines applications comme Proton Authenticator peuvent nécessiter un compte ou un abonnement selon leur version — en cas de doute, préférez Google Authenticator ou Microsoft Authenticator, garanties gratuites.

Option application — Étape 2 : activer le 2FA sur BA38

  1. Allez sur la page de connexion habituelle de BA38.

  2. Cochez la case « Activer la double authentification (première fois seulement) », sous le mot de passe.

  3. Connectez-vous normalement avec votre email et votre mot de passe, puis choisissez « Application d’authentification » sur l’écran qui s’affiche.

  4. Un QR code s’affiche à l’écran.

  5. Ouvrez l’application installée à l’étape 1 sur votre téléphone, et utilisez son bouton pour ajouter un compte (souvent une icône « + »), puis scanner un QR code.

  6. Visez le QR code affiché à l’écran de l’ordinateur avec l’appareil photo du téléphone. Un nouveau compte « BA38 » apparaît dans l’application, avec un code à 6 chiffres.

  7. Recopiez ce code à 6 chiffres dans le champ prévu sur l’écran BA38, puis validez.

  8. Un dernier code vous sera redemandé pour terminer la connexion : ouvrez à nouveau l’application sur votre téléphone et recopiez le code affiché à ce moment-là (il change toutes les 30 secondes, prenez le code affiché au moment où vous le recopiez).

Une fois ces étapes faites, le 2FA est activé définitivement sur votre compte : à chaque connexion future, un code de l’application vous sera demandé en plus de votre mot de passe.

En cas de perte ou de changement de téléphone ou de numéro

Si vous changez de téléphone ou de numéro, ou si vous perdez l’accès à votre application d’authentification, vous ne pourrez plus recevoir ou générer de code. Contactez un administrateur BA38 : il réinitialisera votre 2FA (et le numéro que vous aviez enregistré), puis vous pourrez refaire l’activation avec votre nouveau téléphone.
