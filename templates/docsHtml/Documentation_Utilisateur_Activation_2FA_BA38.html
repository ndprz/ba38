Activer la double authentification (2FA) sur mon compte

Pourquoi activer le 2FA ?

Le 2FA (double authentification) ajoute un code à usage unique, généré par une application sur votre téléphone, en plus de votre mot de passe habituel. Même si quelqu’un devinait ou volait votre mot de passe, il ne pourrait pas se connecter à votre place sans avoir aussi votre téléphone.

C’est rapide à mettre en place (5 minutes) et à utiliser au quotidien (un code à recopier à chaque connexion).

Étape 1 — Installer une application d’authentification sur votre téléphone

Avant de l’activer sur BA38, installez une application gratuite sur votre téléphone (depuis l’App Store sur iPhone, ou le Play Store sur Android).

Applications recommandées, gratuites et sans abonnement :

  • Google Authenticator — la plus simple, aucun compte à créer, il suffit de scanner un QR code.

  • Microsoft Authenticator — équivalente à Google Authenticator, avec en plus une sauvegarde optionnelle liée à un compte Microsoft.

  • 2FAS Auth — alternative gratuite et open source, avec sauvegarde optionnelle.

Toutes ces applications font exactement la même chose : elles affichent un code à 6 chiffres qui change toutes les 30 secondes. Le choix de l’application n’a pas d’importance, du moment qu’elle est installée avant l’étape 2.

Remarque : certaines applications comme Proton Authenticator peuvent nécessiter un compte ou un abonnement selon leur version — en cas de doute, préférez Google Authenticator ou Microsoft Authenticator, garanties gratuites.

Étape 2 — Activer le 2FA sur BA38

  1. Allez sur la page de connexion habituelle de BA38.

  2. Cochez la case « Activer la double authentification (2FA) sur mon compte », sous le mot de passe.

  3. Connectez-vous normalement avec votre email et votre mot de passe.

  4. Un QR code s’affiche à l’écran.

  5. Ouvrez l’application installée à l’étape 1 sur votre téléphone, et utilisez son bouton pour ajouter un compte (souvent une icône « + »), puis scanner un QR code.

  6. Visez le QR code affiché à l’écran de l’ordinateur avec l’appareil photo du téléphone. Un nouveau compte « BA38 » apparaît dans l’application, avec un code à 6 chiffres.

  7. Recopiez ce code à 6 chiffres dans le champ prévu sur l’écran BA38, puis validez.

  8. Un dernier code vous sera redemandé pour terminer la connexion : ouvrez à nouveau l’application sur votre téléphone et recopiez le code affiché à ce moment-là (il change toutes les 30 secondes, prenez le code affiché au moment où vous le recopiez).

Une fois ces étapes faites, le 2FA est activé définitivement sur votre compte : à chaque connexion future, un code de l’application vous sera demandé en plus de votre mot de passe.

En cas de perte ou de changement de téléphone

Si vous changez de téléphone ou perdez l’accès à votre application d’authentification, vous ne pourrez plus générer de code. Dans ce cas, contactez un administrateur BA38 : il pourra réinitialiser votre 2FA, ce qui vous permettra de recommencer l’étape 2 avec votre nouveau téléphone.
