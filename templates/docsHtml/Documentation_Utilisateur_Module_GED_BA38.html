Application BA38 – Engagements
Version de la documentation : 29/06/2026

1. Objectif du module

Le module « GED » (Gestion Électronique des Documents) est une vue de consultation et d’audit de l’ensemble des engagements de dépenses enregistrés dans l’application.

Il permet notamment :
- de visualiser tous les dossiers d’engagement (actifs et archivés),
- d’évaluer la complétude documentaire de chaque dossier (devis, factures, justificatifs, notes de frais),
- de vérifier le rapprochement comptable avec EBP (numéro d’écriture),
- d’identifier les dossiers incomplets ou présentant une anomalie,
- d’exporter les données en Excel pour analyse ou audit externe.

Important : la GED ne permet pas d’ajouter ou de supprimer des documents. Les fichiers sont déposés directement depuis les engagements (création, validation, règlement). La GED est une interface de consultation uniquement.

2. Accès

L’accès à la GED nécessite le droit « lecture » (ou supérieur) sur « Paramètres engagements ». Ce module est destiné au trésorier, à la présidence et au commissaire aux comptes (CAC).

Il n’y a pas de restriction par pôle : un utilisateur autorisé voit l’ensemble des engagements de tous les pôles, y compris les engagements archivés.

3. Accéder à la GED

Menu → Engagements → GED.
Le bouton « ↩︎️ Retour » permet de revenir à la liste des engagements depuis la GED.

4. Filtrer les dossiers

Avant d’afficher des résultats, il faut sélectionner des critères puis cliquer sur « 🔍 Rechercher ». Par défaut, les dates proposées couvrent l’exercice en cours (du 1er janvier à aujourd’hui).

Filtre Description
📅 Date début / 📅 Date fin Période de création des engagements à afficher
🏢 Pôle Limite l’affichage aux engagements d’un pôle donné
🏷️ Rubrique Limite l’affichage à une rubrique comptable
💰 Financement « Budget propre » ou une subvention précise
⚙️ Statut Un des statuts du circuit de validation (voir § 7)
🔢 N° EBP « Avec » ou « Sans » numéro d’écriture comptable EBP
🔍 Rechercher n° EBP Recherche un numéro EBP précis (ou partiel)
📋 Complétude Complets / Incomplets / En cours / Refusés
🗑 Archivés Tous / Actifs uniquement / Archivés uniquement

Le bouton « ✖ Réinitialiser » permet de revenir aux filtres par défaut.

5. Tableau de bord

Après une recherche, quatre indicateurs s’affichent en haut de page :

- Dossiers : nombre total de dossiers trouvés et montant total cumulé,
- Complets ✅ : nombre et pourcentage de dossiers complets,
- Incomplets ⚠️ : nombre de dossiers incomplets, avec le décompte des dossiers réglés sans numéro EBP s’il y en a,
- Avec N° EBP 🔢 : nombre de dossiers rapprochés comptablement et montant réglé correspondant.

6. Tableau des dossiers

Pour chaque engagement trouvé, le tableau affiche : le numéro de dossier, la date de création, le demandeur, le pôle, l’objet et le bénéficiaire (avec le financement associé le cas échéant), la rubrique, le montant, le statut, la date de règlement, le numéro EBP, le nombre de pièces jointes, l’indicateur de complétude, et un bouton « 👁 » pour ouvrir le détail du dossier dans un nouvel onglet.

Les lignes sont colorées selon la complétude : vert pour un dossier complet, orange pour un dossier incomplet, rouge pour un dossier refusé.

Le pied du tableau indique le nombre total de dossiers affichés et le montant cumulé.

7. Indicateur de complétude

Depuis le passage du règlement en deux phases (voir la documentation du module Engagements), le numéro d’écriture EBP n’est plus exigé dès qu’un dossier est réglé : il n’est attendu qu’à partir de la comptabilisation. Chaque dossier reçoit automatiquement l’un des cinq statuts de complétude suivants :

Badge Signification
✅ Complet Dossier comptabilisé ou terminé, avec numéro EBP et toutes les pièces attendues
⚠️ Incomplet Dossier réglé, comptabilisé ou terminé, avec des pièces manquantes (devis, facture/justificatif, note de frais) ou, à partir de la comptabilisation, sans numéro EBP
🔷 En attente compta Dossier réglé, pièces complètes, en attente de comptabilisation (numéro EBP pas encore exigé)
🔵 En cours Le circuit de validation n’est pas terminé ; la complétude n’est pas encore évaluée
🔴 Refusé L’engagement a été refusé

Survoler le badge de complétude dans le tableau affiche le détail des pièces manquantes lorsqu’il y en a.

8. Export Excel

Le bouton « 📥 Export Excel CAC » génère un fichier Excel contenant exactement les dossiers affichés par la recherche en cours, avec les mêmes filtres. Ce fichier est destiné à être transmis à un commissaire aux comptes ou utilisé pour une analyse hors application.

9. Règles métier importantes

  • La complétude est calculée automatiquement ; elle ne se déclare pas manuellement.

  • Un dossier réglé sans numéro EBP n’est pas une anomalie : c’est l’état normal avant comptabilisation. Seul un dossier comptabilisé ou terminé sans numéro d’écriture EBP est signalé par un badge « ❌ Manquant ».

  • Les pièces exigées (devis, facture/justificatif, note de frais) dépendent du montant de l’engagement et des paliers de validation configurés dans le module Engagements.

  • Les engagements archivés restent visibles par défaut dans la GED, qui est une vue d’audit complète.

10. Conseils d’utilisation

  • Toujours vérifier les dossiers « ⚠️ Incomplets » avant une clôture comptable.

  • Utiliser le filtre N° EBP → « Sans N° EBP » pour retrouver rapidement les dossiers réglés non rapprochés.

  • Exporter en Excel avant toute transmission au commissaire aux comptes.

  • Le bouton « 👁 » ouvre le dossier complet (justificatifs, historique) dans un nouvel onglet, sans perdre les filtres en cours dans la GED.

11. Informations techniques

Le module repose principalement sur les éléments suivants :

- Blueprint Flask : engagements_bp
- Module Python : engagements/routes_ged.py
- Template HTML : engagements/ged.html
- Tables SQLite : engagements, engagements_depenses, engagements_fichiers, engagement_poles, engagement_subventions, engagements_parametres

12. Support

En cas de problème :
- vérifier les filtres sélectionnés (dates, pôle, statut),
- vérifier le numéro EBP saisi en trésorerie,
- contacter le service informatique BA38.
