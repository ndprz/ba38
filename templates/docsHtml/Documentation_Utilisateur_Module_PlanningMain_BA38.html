Aide – Planning des Bénévoles

Cette page est le point d’entrée du module Planning. Elle donne accès à cinq types de planning (Ramasse, Distribution, Palettes, Pesée, VIF) ainsi qu’à plusieurs outils transverses.

Les types de planning

Chaque type de planning dispose de sa propre carte, avec deux actions :

  • 🔧 Mise à jour modèle : définit le modèle récurrent du planning (les créneaux et bénévoles qui se répètent d’une période à l’autre), sans créer de dates concrètes.

  • ➕ Création planning : génère, à partir du modèle, le planning réel sur une période donnée.

Une aide spécifique à chaque type de planning sera disponible directement sur ses écrans.

Outils transverses

  • 📅 Gérer les absences des bénévoles : permet de déclarer les périodes d’indisponibilité d’un bénévole, prises en compte lors de la génération des plannings.

  • 🛠️ Gestion des tournées : configure les tournées utilisées par les plannings de ramasse.

  • 📋 État des plannings : permet de voir et réimprimer un planning existant dans l’historique.

  • 📊 Rapport activité bénévoles : génère un rapport sur l’activité des bénévoles à partir des plannings.

Accès

Ce module est accessible uniquement aux comptes disposant du droit de lecture sur “planning”. Sans ce droit, un message l’indique et aucune carte n’est affichée.
