Aide – Envoi de mail bénévoles

Cet écran permet de préparer un email groupé à destination de plusieurs bénévoles, puis de l’envoyer via Gmail.

Fonctionnement de l’envoi

L’envoi ne se fait pas directement depuis BA38 : le bouton “📤 Ouvrir Gmail” ouvre un nouvel onglet avec un brouillon Gmail déjà rempli (destinataires, sujet, message). Il faut ensuite cliquer sur “Envoyer” dans Gmail pour finaliser l’envoi.

  • Le champ À : contient automatiquement votre propre adresse email.

  • Les bénévoles sélectionnés sont ajoutés en CCI (copie cachée), afin que leurs adresses email ne soient pas visibles des uns des autres.

Filtrer les destinataires par fonction

En haut de la page, cocher une ou plusieurs fonctions limite la liste des destinataires proposés aux bénévoles correspondants. Le nombre de bénévoles trouvés est affiché sous les cases à cocher.

Choisir les destinataires

Dans la liste “Destinataires”, cocher chaque bénévole à qui envoyer le mail, ou utiliser “Tout sélectionner” pour cocher toute la liste affichée.

Rédiger le message

  • Sujet : obligatoire.

  • Message : le corps du mail.

  • Utiliser un message pré-enregistré : sélectionner un modèle dans la liste remplit automatiquement le sujet (s’il est vide) et le message avec le contenu du modèle choisi. Le texte reste ensuite modifiable avant l’envoi. Les modèles eux-mêmes se gèrent via le bouton “⚙️ Gérer les messages pré-enregistrés”.

Envoyer

Une fois les destinataires et le message prêts, cliquer sur “📤 Ouvrir Gmail” : un message d’erreur s’affiche si aucun destinataire n’est sélectionné. Si votre compte BA38 n’a pas d’adresse email enregistrée, un avertissement le signale (le champ “À :” restera alors vide dans Gmail).
