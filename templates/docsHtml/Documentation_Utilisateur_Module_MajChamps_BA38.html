Aide – Mise à jour des Champs

Cet écran de paramétrage définit quels champs existent et comment ils s’affichent dans les formulaires et les listes d’un module (Bénévoles, Partenaires ou Fournisseurs selon la plateforme indiquée en haut de la page). C’est un écran technique, réservé aux comptes disposant des droits d’administration.

⚠️ Attention : les modifications faites ici changent immédiatement la structure des formulaires et des listes du module concerné, pour tous les utilisateurs.

Le tableau des champs existants

Les champs déjà configurés sont regroupés par thème (accordéon : cliquer sur le titre d’un groupe pour l’ouvrir). Pour chaque champ, il est possible de modifier :

  • Nom du Champ : le champ de la base de données auquel correspond cette ligne.

  • Groupe : le regroupement thématique sous lequel le champ apparaît dans les formulaires et les “Options d’affichage”.

  • Type : le type de saisie associé (texte, email, téléphone, oui/non, liste, etc.), qui détermine comment le champ est affiché et validé.

  • Ordre : la position d’affichage du champ à l’intérieur de son groupe.

  • ✖ : supprime immédiatement ce champ de la configuration (une confirmation est demandée). Le champ disparaît alors des formulaires et listes du module, mais les données déjà enregistrées en base ne sont pas supprimées.

Le bouton “✅ Enregistrer” en bas de tableau applique en une seule fois toutes les modifications de nom/groupe/type/ordre faites sur les lignes existantes.

Ajouter un nouveau champ

La section “Ajouter un nouveau champ” en bas de page permet d’ajouter à la configuration un champ existant en base mais pas encore affiché nulle part (menu déroulant “Champ”), en lui choisissant un groupe, un type et un ordre d’affichage. Cet ajout est immédiat, indépendant du bouton “Enregistrer” du tableau principal.

Attention en quittant la page

Contrairement à d’autres écrans de saisie de BA38, quitter cette page (bouton “Retour”, navigation) n’affiche pas d’avertissement en cas de modifications non enregistrées : pensez à cliquer sur “✅ Enregistrer” avant de partir si vous avez modifié une ligne du tableau.
