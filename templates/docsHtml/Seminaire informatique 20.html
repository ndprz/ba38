  • Google Drive pour ordinateur

    • Installer sur son poste, pc perso ou de la BAI le programme google drive pour ordinateur

      https://support.google.com/drive/answer/10838124?hl=fr

      S’installe sur Windows ou Mac

      Avant de l’installer, se connecter dans Chrome avec son mail banquealimentaire.org pour que le disque virtuel créé pointe sur les bons fichiers

      Google Drive pour Ordinateur créera sur le poste une lettre g : qui pointe vers Mon Drive et les Drive Partagé autorisés (comme un disque externe ou une clé USB)

      Et donc quand on double clique sur un fichier dans cette lettre g: dans l’explorateur Windows ou le Finder MacOs, ça ouvrira l’application prévue sur le poste et pas l’application google.

      ex : fichier Excel, si vous avez un office sur votre poste, il s’ouvrira dans votre programme Excel. PDF, dans adobe, etc.

      Si vous avez déjà cette lettre G :, sachez qu’on peut voir plusieurs comptes google dans G : (me demander)
