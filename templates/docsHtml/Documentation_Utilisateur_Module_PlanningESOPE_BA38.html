Aide – Planning ESOPE

Le planning ESOPE remplace le fichier Excel de l’épicerie sociale. On décrit une fois la semaine type, puis Basilic construit le planning de chaque mois ; il ne reste qu’à le retoucher et l’imprimer.

Version du 30/10/2026. Les bénévoles reçoivent leurs créneaux par mail et répondent en ligne avec un lien personnel, sans compte Basilic.

Mise en route, dans l’ordre

  1. ⚙️ Paramétrage : vérifier les fonctions, les postes et les horaires habituels.
  2. 👥 Bénévoles ESOPE : cocher pour chaque bénévole ses fonctions possibles et ses jours de disponibilité.
  3. 🚫 Jours de fermeture (lien sur la page d’accueil ESOPE) : saisir les jours fériés et les congés.
  4. 🔁 Planning modèle : placer les bénévoles réguliers dans la semaine type.
  5. ⚙️ Générer le mois depuis la page d’accueil ESOPE.
  6. 📅 Planning : retoucher semaine par semaine, puis imprimer.
  7. 📨 Envoi aux bénévoles : envoyer à chacun ses créneaux, suivre les réponses, verrouiller le mois.

Les étapes 1 à 4 ne se font qu’une fois ; ensuite, il suffit de les tenir à jour.

Paramétrage

Réservé aux personnes qui ont le droit d’écriture sur le planning ESOPE.

Fonctions : Accueil, Caisse-Pesée, Support, etc. L’ordre fixe la position des lignes dans le planning. Une fonction désactivée disparaît du planning, du modèle et des cases à cocher.

Créneaux habituels : une ligne par poste et par jour, avec ses horaires et le nombre de bénévoles attendus.

  • Poste : à remplir quand une fonction a plusieurs postes aux horaires différents (Caisse-Pesée : Poste 1, 2, 3). Sinon, laisser vide.
  • Min : en dessous, la case du planning passe en rouge (poste non couvert).
  • Max : on ne peut pas placer plus de bénévoles que ce nombre.
  • Précision : un mot affiché à côté des horaires (ex. « sushis » pour la mise en rayon du mercredi).

Cliquer sur 💾 au bout de la ligne pour enregistrer. Une ligne neuve en bas du tableau sert à ajouter un créneau.

Les changements de paramétrage ne valent que pour les mois générés ensuite. Pour changer un seul jour, passer par ⚙️ dans le planning.

Bénévoles ESOPE

La liste contient les bénévoles dont le champ « esope » vaut oui dans leur fiche. Pour ajouter quelqu’un à l’ESOPE, ouvrir sa fiche bénévole et mettre ce champ à oui.

Pour chaque bénévole, cocher :

  • les fonctions qu’il ou elle peut tenir ;
  • les jours où il ou elle est disponible ;
  • un commentaire si besoin (ex. « préfère l’accueil », « pas de port de charges »).

Chaque case est enregistrée dès qu’on la coche ; le contour passe brièvement au vert.

Les mêmes informations se trouvent dans la fiche du bénévole, bloc « 🛒 ESOPE » (bouton « Enregistrer le profil ESOPE »).

Ces informations servent à proposer les bons noms en premier quand on place quelqu’un sur un créneau. Elles n’interdisent rien : on peut toujours choisir un autre bénévole.

Planning modèle

C’est la semaine type : qui vient sur quel poste, chaque semaine ou une semaine sur deux.

La page s’affiche sur fond violet, avec un bandeau « SEMAINE TYPE », pour ne pas la confondre avec le planning réel.

  • Cliquer sur ➕ ajouter dans une case, choisir le bénévole et la fréquence.
  • Une semaine sur deux (ou sur trois, sur quatre) : indiquer une date où la personne vient. L’alternance part de cette semaine-là.
  • Deux bénévoles qui alternent sur le même poste sont tous les deux dans la case, chacun avec sa propre date.
  • Arrive à / Part à : à remplir seulement si la personne n’est présente qu’une partie du créneau.
  • Cliquer sur un nom pour le modifier ou le retirer du modèle.

Une case rouge n’a encore personne. Un avertissement apparaît si trop de personnes viennent chaque semaine pour le nombre de places.

Modifier le modèle ne change pas les mois déjà générés.

Générer un mois

Sur la page d’accueil ESOPE, le tableau montre les quatre prochains mois.

  • ⚙️ Générer : crée tous les créneaux du mois (sauf les jours de fermeture) et y place les bénévoles du modèle.
  • ➕ Compléter (mois déjà généré) : ajoute seulement ce qui manque. Rien de ce qui a été retouché n’est modifié.
  • 🔄 Réinitialiser depuis le modèle (bas du tableau, pour n’importe quel mois) : efface le mois et le reconstruit à partir du modèle. Toutes les retouches du mois sont perdues ; les événements sont conservés. Une confirmation est demandée.

Penser à saisir les jours de fermeture avant de générer : ajoutés après, ils ne retirent pas les créneaux déjà créés.

Planning de la semaine

Une ligne par fonction et par poste, une colonne par jour, du lundi au samedi. Les flèches et le calendrier en haut de page changent de semaine.

Couleurs :

  • rouge : pas assez de bénévoles (poste non couvert) ;
  • jaune : plus de bénévoles que prévu ;
  • gris : créneau ou jour fermé ;
  • ✔ devant un nom : présence confirmée ;
  • nom barré : absence (statut Annulé, ou absence saisie dans « Absences », signalée par 🏖️) ;
  • horaires entre parenthèses, en violet : présence sur une partie du créneau seulement.

Ajouter un bénévole : cliquer sur ➕ ajouter dans la case. La liste propose d’abord les bénévoles qui ont cette fonction et sont disponibles ce jour-là, puis les autres.

Modifier ou retirer un bénévole : cliquer sur son nom. On peut changer :

  • le statut : Prévu, Confirmé, ou Annulé (absence) ;
  • les horaires partiels ;
  • le commentaire (signalé par 💬).

Pour une absence, choisir le statut Annulé plutôt que de retirer le bénévole : son nom reste visible barré et la place se libère. Pour une absence qui dure (congés, maladie…), utiliser plutôt la page Absences (voir plus bas).

Modifier le créneau d’un jour : cliquer sur ⚙️ en haut de la case. On peut changer les horaires, le nombre de bénévoles, ajouter un commentaire ou fermer le créneau ce jour-là. Cela ne touche que ce jour.

Écrire aux bénévoles : ✉️ ouvre Gmail dans un nouvel onglet, avec tous les bénévoles du créneau en copie cachée. Le bouton 📱 SMS bénévoles ESOPE ouvre l’envoi de SMS déjà filtré sur l’ESOPE.

Absences

Bouton 🏖️ Absences : signaler qu’un bénévole est absent un jour, une période ou un mois (congés, maladie, absence annoncée par mail ou par téléphone).

  • Choisir le bénévole (seuls les bénévoles ESOPE sont listés), puis les dates Du… Au… (inclus). Si « Au » est vide, c’est un seul jour.
  • Dès l’enregistrement, le bénévole est mis en absent sur tous ses créneaux ESOPE de la période : nom barré avec 🏖️ à l’écran, absent de l’impression et du PDF, place signalée libre, plus de créneaux dans les mails ni de rappel de la veille pour ces dates.
  • Le tableau montre les absences en cours ou à venir (👁️ pour voir toutes) et le nombre de créneaux concernés. On peut modifier les dates (💾) ou supprimer l’absence (🗑) : les créneaux redeviennent alors actifs.

Ces absences sont communes à tous les plannings de Basilic (même liste que « Gérer les absences des bénévoles » dans Plannings) : une absence saisie ici vaut aussi pour la distribution et la cuisine. Si un mois est généré alors qu’une absence est déjà saisie, le bénévole est placé comme d’habitude mais apparaît directement absent.

Événements

Pour une action ponctuelle (collecte, fête, formation…) : bouton 🎉 Événements, puis remplir le libellé, la date, le lieu, les horaires et le nombre de bénévoles.

L’événement apparaît sous la grille de la semaine concernée. On y place les bénévoles comme dans une case habituelle (➕ ajouter, clic sur un nom, ⚙️).

Imprimer

Depuis le planning de la semaine :

  • 🖨️ Imprimer la semaine : une page A4 paysage ;
  • 🖨️ Imprimer le mois : une page par semaine.

Dans la fenêtre d’impression du navigateur, choisir le format paysage et décocher les en-têtes et pieds de page. Sur papier, ⚠ signale un poste non couvert et les pointillés une place libre. Les bénévoles absents (statut Annulé ou absence saisie) n’apparaissent pas sur l’impression ni dans le PDF joint aux mails ; ils restent visibles à l’écran.

Envoi aux bénévoles

Bouton 📨 Envoi aux bénévoles, puis choisir le mois avec les flèches ou le calendrier. Le mois doit déjà être généré.

Mode TEST ou réel : le bouton en haut à droite de l’encadré bascule entre les deux.

  • 🧪 Mode TEST (bandeau jaune) : 2 mails au plus, tous envoyés à vous. Les bénévoles ne reçoivent rien. C’est le mode de départ.
  • 🚀 Mode RÉEL (bouton rouge) : les mails partent vraiment aux bénévoles.

📨 Envoyer le pré-planning : chaque bénévole reçoit un mail avec :

  • la liste de ses créneaux du mois ;
  • le planning complet du mois en PDF ;
  • son lien personnel, pour confirmer ou annuler chaque créneau.

La case « aussi aux bénévoles sans créneau » leur envoie le mail pour qu’ils proposent leurs disponibilités. Un bénévole qui a déjà reçu le mail n’est pas relancé par ce bouton.

Mois entier ou une semaine : au-dessus du bouton, choisir « Le mois entier » ou « Une semaine seulement » (et la semaine). Pour une semaine, chaque bénévole qui a un créneau cette semaine-là reçoit un mail avec seulement ses créneaux de la semaine et le planning de la semaine en PDF, même s’il a déjà reçu le mois. Le suivi des réponses du mois n’est pas modifié.

🔔 Relancer les sans réponse : renvoie un mail à ceux qui ont des créneaux et n’ont pas encore répondu.

Tableau de suivi : une ligne par bénévole, avec son nombre de créneaux, de confirmations, d’annulations et de créneaux sans réponse, et son état (à envoyer, envoyé, lien ouvert, a répondu, erreur d’envoi, pas de mail). Au bout de la ligne :

  • ✉️ : envoyer ou renvoyer le mail à ce bénévole seulement ;
  • 📝 : ouvrir sa page pour saisir ses réponses à sa place (bénévole sans mail, réponse donnée par téléphone) ;
  • 🔗 : copier son lien personnel (pour le lui transmettre autrement).

Les réponses aux mails (bouton « Répondre » de la messagerie) arrivent dans la boîte de la responsable ESOPE.

Ce que voit le bénévole

En cliquant sur son lien, le bénévole arrive sur une page « Mes créneaux », lisible sur téléphone :

  • ✔ Je confirme ou ✖ J’annule, créneau par créneau, avec un commentaire possible (retard, départ plus tôt…) ;
  • ✔ Je confirme tous mes créneaux en un clic (les créneaux déjà annulés restent annulés) ;
  • 📝 Mes disponibilités : un texte libre pour proposer son aide sur d’autres jours ou postes ;
  • un lien vers le planning complet du mois.

Le bénévole peut changer d’avis tant que le mois n’est pas verrouillé.

Réponses des bénévoles et alertes

Chaque réponse d’un bénévole envoie aussitôt un mail d’alerte à la responsable ESOPE (ba380.esoperesponsable@banquealimentaire.org).

Les réponses s’affichent aussi :

  • en haut de la page Envoi aux bénévoles, dans ⚠️ Réponses des bénévoles à voir ;
  • dans le planning de la semaine : le nom du bénévole est surligné en jaune, avec ⚠.

Cliquer sur Vu (ou Tout marquer comme vu) retire la réponse de la liste. Elle reste enregistrée : le lien Afficher aussi les réponses déjà vues les montre toutes. Enregistrer une modification du bénévole depuis le planning vaut aussi « vu ».

Verrouiller le mois

Une fois le planning définitif, cliquer sur 🔒 Verrouiller le mois (page Envoi aux bénévoles).

  • Les bénévoles ne peuvent plus confirmer.
  • Ils peuvent toujours annuler (« Je ne pourrai pas venir ») : la responsable reçoit l’alerte tout de suite.
  • Le gestionnaire peut toujours tout modifier dans le planning.

🔓 Déverrouiller rend de nouveau les confirmations possibles.

Textes des mails

Bouton ✏️ Textes des mails (page Envoi aux bénévoles) : objet et texte du pré-planning, de la relance et du rappel de la veille.

Les mots entre chevrons sont remplacés pour chaque bénévole : <<prenom>>, <<nom>>, <<mois>>, <<creneaux>> (sa liste de créneaux), <<lien>> (son lien personnel). Ne pas les supprimer.

Rappel la veille

Quand il est activé, un mail de rappel part chaque jour aux bénévoles attendus le lendemain (créneaux prévus ou confirmés, mois envoyé ou verrouillé). Il contient leur lien, pour signaler une absence de dernière minute.

Historique

Le lien historique de la page d’accueil ESOPE liste les 300 dernières actions : qui a ajouté, modifié ou retiré qui, et quand.

Droits d’accès

  • Lecture : voir et imprimer le planning, le modèle, les événements et la liste des bénévoles.
  • Écriture : tout le reste (paramétrage, modèle, génération, modifications).

Les droits se donnent dans Administration → Utilisateurs, application « Planning ESOPE ».
