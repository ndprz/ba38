Sécurité des connexions à Basilic (généré par IA)

Oct 15, 2026 · @Nicolas DUPRAZ

Ce guide sert de support au séminaire informatique du mardi 20 octobre 2026. La partie 1 présente les protections mises en place et les décisions à prendre. La partie 2 est le mode d'emploi à remettre aux utilisateurs. La partie 3 donne les conseils pour choisir un bon mot de passe.

Partie 1 — Ce que nous mettons en place

Pourquoi renforcer la sécurité

Basilic contient les coordonnées de nos bénévoles, celles des associations partenaires et des données financières. Un compte piraté expose ces personnes et engage la responsabilité de l'association au titre du RGPD.

Les attaques qui visent les associations sont presque toujours les mêmes :

  • le faux email (hameçonnage) qui imite un message officiel pour vous faire taper votre mot de passe sur un faux site ;

  • les essais automatiques de milliers de mots de passe sur la page de connexion, jour et nuit ;

  • la réutilisation d'un mot de passe volé sur un autre site (boutique en ligne, réseau social) où vous aviez mis le même.

Dans les trois cas, le mot de passe seul ne suffit plus : celui qui le connaît peut entrer, depuis n'importe où. Notre objectif est de bloquer ces attaques sans compliquer la vie des bénévoles : la plupart des protections sont invisibles, et la seule nouveauté visible est un code de connexion, demandé au plus une fois tous les 6 jours sur un même appareil.

Déjà en place depuis le 15 octobre, sans rien changer pour vous

Cinq protections fonctionnent depuis la version 1.7.119 de Basilic. Elles ne demandent rien aux utilisateurs tant que tout va bien.

Nous avons aussi corrigé quatre failles techniques : l'adresse d'origine d'une connexion pouvait être falsifiée, le blocage après plusieurs échecs ne bloquait rien, le code de double authentification pouvait être essayé sans limite, et un compte désactivé restait connecté jusqu'à 24 heures.

Ce qui va changer : le code de connexion

La nouveauté visible est la double authentification : après le mot de passe, Basilic demande un code à 6 chiffres envoyé par SMS ou par email. Un pirate qui a volé le mot de passe ne reçoit pas ce code, il reste donc dehors.

Pour que ce soit supportable au quotidien :

  • le code n'est demandé qu'une fois tous les 6 jours sur un même ordinateur ou téléphone ;

  • un compte partagé (secrétariat, bénévoles qui se relaient) peut avoir un numéro de portable par personne : chacun choisit le sien dans une liste où les numéros sont masqués ;

  • sans portable enregistré, le code arrive par email à l'adresse du compte ;

  • ceux qui le souhaitent peuvent utiliser une application d'authentification à la place.

C'est l'administrateur qui active le code compte par compte, et qui enregistre les numéros de portable. Un utilisateur ne peut pas ajouter son numéro lui-même : sinon, un pirate qui aurait le mot de passe pourrait ajouter le sien.

Calendrier proposé

  1. Les 3 administrateurs, dès la semaine du séminaire.

  2. Les comptes sensibles : trésorerie, comptabilité, bénévolat, données des associations.

  3. Tous les autres comptes, par vagues, après distribution de la partie 2 de ce guide.

Partie 2 — Mode d'emploi pour les utilisateurs

Se connecter avec un code

Vous tapez votre email et votre mot de passe comme d'habitude. Si le code est activé pour votre compte, Basilic vous demande ensuite de confirmer que c'est bien vous.

  1. L'écran « Où voulez-vous le recevoir ? » s'affiche. Cliquez sur votre prénom (le numéro est en partie caché, par exemple 06 •• •• •• 12) pour recevoir le code par SMS, ou sur « Par email ».

  2. Le code à 6 chiffres arrive en quelques secondes. Il est valable 10 minutes.

  3. Tapez-le dans la case de l'écran « Entrez le code reçu ». Sur un téléphone, le clavier propose souvent le code tout seul.

  4. Laissez cochée la case « Ne plus me demander de code sur cet appareil pendant 6 jours », puis cliquez sur Valider.

Pendant les 6 jours suivants, sur ce même ordinateur ou téléphone et avec le même navigateur, le mot de passe suffit.

Quand décocher la case des 6 jours ? Sur un ordinateur utilisé par d'autres personnes que vous (accueil, poste en libre-service) si vous vous connectez avec votre compte personnel. Sur le poste habituel d'un compte partagé, laissez-la cochée.

Pas reçu le code ? Attendez une minute, puis cliquez sur « renvoyer un code ou choisir un autre moyen ». Vous pouvez demander 3 codes par quart d'heure au maximum. Utilisez toujours le dernier code reçu.

Compte partagé (secrétariat, bénévoles qui se relaient selon les jours) : chaque personne a sa ligne dans la liste, avec son prénom. Cliquez sur le vôtre : le code arrive sur votre portable. Si votre prénom n'apparaît pas, demandez à l'administrateur d'ajouter votre numéro.

Application d'authentification (facultatif) : si vous utilisez déjà Google Authenticator ou une application semblable, cochez « Activer la double authentification » sur l'écran de connexion et scannez le QR code proposé. Le code se lit alors dans l'application, sans SMS ni email. Le lien « Recevoir un code par SMS ou email » reste disponible le jour où le téléphone n'est pas là.

Ce que fait « Ce n'est pas moi » : toutes les connexions ouvertes sur votre compte sont coupées, l'ancien mot de passe ne fonctionne plus, et vous recevez un email pour en choisir un nouveau (valable 24 heures). L'équipe informatique est prévenue automatiquement.

En cas de problème

J'ai oublié mon mot de passe. Cliquez sur « Mot de passe oublié ? » sur la page de connexion. Vous recevez un email pour en choisir un nouveau. Pas besoin d'attendre le support.

Mon compte est bloqué. Attendez 15 minutes : il se débloque tout seul. Si vous n'êtes plus sûr de votre mot de passe, utilisez « Mot de passe oublié » plutôt que de réessayer.

Je pars à l'étranger et je dois me connecter. Prévenez le support avant le départ, avec vos dates. L'administrateur autorise votre compte jusqu'à la date de retour. Avec un forfait mobile français utilisé en Europe, la connexion depuis votre téléphone passe en général sans autorisation ; c'est le wifi d'un hôtel ou d'un café à l'étranger qui sera bloqué.

Je ne reçois pas le code. Vérifiez vos courriers indésirables (spam) pour l'email. Pour le SMS, attendez une minute, puis redemandez un code ou choisissez « Par email ». Si votre numéro a changé, prévenez le support.

J'ai changé de téléphone ou d'ordinateur. Rien à faire : vous recevrez l'email « Nouvelle connexion » et le code sera redemandé une fois sur le nouvel appareil.

Pour tout le reste : sur la page de connexion, cliquez sur « Problème de connexion ? Écrire au support ». Indiquez votre nom, un email ou un téléphone pour vous répondre, et ce qui se passe. N'écrivez jamais votre mot de passe dans ce message. Vous pouvez aussi écrire directement à ba380.informatique2@banquealimentaire.org.

Partie 3 — Bien choisir son mot de passe

La phrase de passe : longue, facile à retenir et à taper

Un bon mot de passe est long, pas compliqué. Quatre ou cinq mots ordinaires mis bout à bout résistent mieux aux attaques que « Banque2026! », et ils se retiennent sans post-it.

La méthode en 3 étapes

  1. Pensez à une image qui ne parle qu'à vous : un souvenir, un lieu, une scène un peu absurde.

  2. Décrivez-la en 4 ou 5 mots, séparés par des espaces.

  3. Vérifiez qu'elle fait au moins 16 caractères, espaces compris.

Exemples pour comprendre la méthode (ne les utilisez pas, ils sont publiés ici) :

  • le chat roux dort sous le tilleul

  • velo bleu dans la cave de mamie

  • trois poireaux pour la soupe du jeudi

Pour qu'elle soit facile à taper, sur un ordinateur comme sur un téléphone :

  • tout en minuscules, pour ne pas jongler avec la touche majuscule ;

  • sans accents ni caractères spéciaux, qui se cachent sur le clavier d'un téléphone ou d'un ordinateur étranger ;

  • avec des espaces entre les mots : Basilic les accepte, et la phrase se relit comme une vraie phrase.

À éviter : votre nom, celui de vos proches ou de votre animal, une date de naissance, une citation ou un titre de chanson connus, une suite de clavier (azerty, 123456), et le même mot de passe que pour votre messagerie ou un autre site.

Basilic accepte aujourd'hui un mot de passe de 6 caractères. La règle retenue au séminaire (par exemple 12 caractères minimum) s'appliquera au prochain changement de mot de passe.

Laisser le navigateur retenir le mot de passe

Le plus simple est de laisser le navigateur mémoriser le mot de passe : il le remplit tout seul à chaque connexion.

  • Chrome (ordinateur et Android) et Edge proposent d'enregistrer le mot de passe après la première connexion : cliquez sur « Enregistrer ».

  • iPhone, iPad et Mac : Safari l'enregistre dans le trousseau iCloud.

  • Firefox fait de même.

  • Pour ceux qui utilisent plusieurs appareils différents, Bitwarden (gratuit) les garde tous au même endroit.

Jamais sur un ordinateur partagé (accueil, entrepôt, poste en libre-service) : la personne suivante pourrait se connecter avec votre compte. Et votre ordinateur ou téléphone doit lui-même être protégé par un code de verrouillage.

Les règles d'or

  • Ne donnez jamais votre mot de passe ni un code reçu par SMS ou email, à personne. L'équipe informatique ne vous les demandera jamais, ni par email ni par téléphone.

  • Vérifiez l'adresse avant de taper votre mot de passe : la vraie page de connexion est sur ba380.org. Un email qui vous presse (« votre compte sera supprimé ») avec un lien vers une autre adresse est un piège.

  • Un doute ? Changez votre mot de passe avec « Mot de passe oublié » et prévenez le support. Ce n'est jamais une gêne.
