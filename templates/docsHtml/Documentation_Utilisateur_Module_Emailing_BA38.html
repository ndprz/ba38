Emailing : envoyer un message aux associations ou aux bénévoles

À quoi ça sert

Cet écran permet d’envoyer le même message à plusieurs destinataires (toutes les associations, ou des bénévoles choisis par fonction), de suivre ce qui a été délivré, de renvoyer par Gmail les mails en échec et, si besoin, de joindre un formulaire de réponse (oui/non, texte court).

On y accède par le bouton « 📣 Emailing associations » (page Partenaires) ou « 📣 Emailing bénévoles » (page Bénévoles). Les deux écrans sont identiques ; seule la façon de choisir les destinataires change.

Les 4 étapes d’une campagne

1. Créer la campagne. Sur la liste des campagnes, saisissez le sujet puis « ➕ Créer une campagne ». Une campagne = un message + une liste de destinataires + son suivi.

2. Rédiger le message. Carte « Message et expéditeur » :

  • choisissez un modèle existant (catégorie « Emailing associations ») ou écrivez directement le texte ;
  • les images se collent dans le texte (ou bouton image de la barre d’outils) ;
  • choisissez l’expéditeur (liste des adresses validées chez Mailjet), éventuellement un nom affiché et une adresse de réponse ;
  • vous pouvez enregistrer le texte comme nouveau modèle pour le réutiliser.

3. Choisir les destinataires.

  • Associations : cochez les types d’adresses voulus (association, président, resp. IE1, trésorerie, accueil, collecte…) ou « Tous les types ». Option « Seulement les associations valides ».
  • Bénévoles : « Tous les bénévoles », « Sans aucune fonction », ou une ou plusieurs fonctions (un bénévole est retenu s’il a « oui » dans au moins une des fonctions cochées). On peut restreindre par type (bénévole, salarié, stagiaire…).

Cliquez ensuite sur « 📋 Construire la liste ». Une même adresse n’apparaît qu’une seule fois.

4. Vérifier, décocher, envoyer. La liste d’envoi est triée par nom. Décochez les lignes à ne pas servir (la coche est enregistrée tout de suite). Vous pouvez trier (clic sur un en-tête) et filtrer par texte, par statut et, pour les bénévoles, par fonction.

Les variables du message

Un clic sur une variable la copie ; collez-la ensuite (Ctrl+V) dans le texte, à l’endroit voulu.

  • <<nom_association>> (associations) ou <<prenom>> / <<nom>> (bénévoles) ;
  • <<fonction>> : le type d’adresse ou les fonctions du destinataire ;
  • <<lien_formulaire>> : le lien personnel du formulaire de réponse (voir plus bas).

Envoyer

La case « Mode TEST » est cochée par défaut : l’envoi est alors limité à 2 mails, adressés à vous, et le sujet porte « [TEST] ». Faites toujours un test avant le premier envoi réel : vous contrôlez le texte, les images et le lien du formulaire.

Pour un envoi réel, décochez « Mode TEST » : une confirmation indique le nombre d’adresses. L’envoi se fait en arrière-plan ; actualisez la page pour voir l’avancement.

Important : un envoi réel ne repart jamais deux fois vers une adresse déjà servie avec succès. Les adresses en erreur sont reprises au prochain envoi.

Suivre la campagne

Le tableau de suivi indique, pour chaque adresse, la date d’envoi et le statut Mailjet. Cliquez sur « 🔄 Vérifier statut Mailjet » : la vérification se fait en arrière-plan (actualisez la page ensuite), et la date de dernière vérification s’affiche.

  • Délivré (ouverture non détectée) : le mail est arrivé. Cela ne veut pas dire « non lu » : certaines messageries bloquent le suivi des ouvertures.
  • Lu / Cliqué : une ouverture ou un clic a été détecté (chiffre minimum).
  • Rebond, Bloqué, Classé spam, Remise différée : échec de remise.
  • Erreur d’envoi : Mailjet a refusé le mail (adresse invalide…).

Vous pouvez trier et filtrer le suivi par statut (délivrés, lus, erreurs, tests, à envoyer, décochés).

En cas d’échec : renvoi par Gmail

Le bouton 🔁 d’une ligne (ou « Renvoyer les échecs par Gmail » pour toutes) renvoie le mail depuis la boîte Gmail générale. Utile pour les rebonds de certaines messageries (Microsoft, mail.ru). Le mail part toujours de l’adresse Gmail de la BA ; l’adresse choisie comme expéditeur est mise en « Répondre à ».

Renvoyer la campagne

Une fois la campagne envoyée, le bouton « 🔁 Renvoyer la campagne » envoie de nouveau le message à toutes les lignes cochées, même celles qui l’ont déjà reçu (par exemple après correction du texte ou ajout d’un formulaire). Vous pouvez ajouter « Rappel : » ou « Mise à jour : » devant le sujet. Les destinataires déjà servis plusieurs fois portent un badge « 2 envois ». Décochez les lignes à ne pas déranger avant de renvoyer.

Joindre un formulaire de réponse

Dans la carte « Formulaire de réponse » :

  1. cochez « Joindre un formulaire » ;
  2. saisissez un titre, un texte d’introduction et un message de remerciement (facultatifs) ;
  3. ajoutez vos questions : Oui/Non ou Texte court, chacune facultative ou obligatoire ;
  4. cliquez sur « Enregistrer le formulaire » ;
  5. placez <<lien_formulaire>> dans le texte du mail (copier-coller de la variable, ou bouton « Insérer le lien au curseur ») puis enregistrez le message.

Chaque adresse reçoit un lien personnel : la réponse est rattachée automatiquement à la bonne association ou au bon bénévole, sans connexion. Une réponse par adresse, modifiable à tout moment avec le même lien.

Une alerte orange s’affiche si le formulaire est activé mais que le texte ne contient pas le lien : sans lui, les destinataires ne recevraient aucun lien.

Exploiter les réponses

  • La colonne « Réponse » du suivi indique qui a répondu et quand ; le badge « Répondus N / N » donne l’avancement.
  • Le tableau « Réponses » liste toutes les réponses ; le bouton « 📊 Export Excel » les exporte (les non-répondants figurent avec des cases vides).
  • « 🔔 Relancer les non-répondants » renvoie le message (sujet « Relance : … ») aux adresses servies, cochées, qui n’ont pas répondu. Case « Test » cochée par défaut.

Bon à savoir

  • En mode TEST, le lien du formulaire est celui de l’adresse concernée : une réponse faite depuis un test est enregistrée pour cette adresse.
  • Supprimer une question efface ses réponses.
  • Une campagne déjà envoyée en réel ne peut pas être supprimée (traçabilité).
  • Les adresses multiples ou invalides sont ignorées ; les champs « Sans » ne sont pas des adresses.
  • Il n’y a pas de lien de désinscription : réservez l’outil aux messages d’information à vos partenaires et bénévoles.
