Documentation Utilisateur — Traitement fichier de participation pour EBP

Objectif

Préparer le fichier PARSOL2L de participation de solidarité (issu de VIF) avant de le transmettre au comptable pour intégration dans la comptabilité EBP : retirer les livraisons du vendredi, samedi et dimanche (non facturées) et déposer les fichiers résultants sur le Drive partagé.

Cet écran ne génère ni facture, ni email aux associations — pour cela, utiliser le module “📊 Facturation participation (V2)”.

  1. Accéder à l’écran

Menu → Trésorerie → section “Participation” → “📂 Traitement fichier de participation pour EBP”.

  1. Préparer le fichier dans VIF

  • Créer, s’il n’existe pas encore, un dossier pour le trimestre concerné sur le Drive partagé (exemple : G:partagés - TRESORERIE\2026 T2).

  • Dans VIF, lancer PARSOL2L et enregistrer le fichier obtenu dans ce dossier (exemple : 20263T2_parsol2l.txt).

  1. Lancer le traitement

  • Sur l’écran BA38, sélectionner ce fichier .txt puis cliquer sur “Lancer le traitement”.

  • Le fichier est analysé : les livraisons du vendredi, samedi et dimanche sont retirées, les totaux recalculés.

  1. Résultat

Le trimestre est déduit automatiquement de la première date trouvée dans le fichier. Le dossier Drive correspondant (créé s’il n’existe pas, nettoyé de son contenu précédent sinon) reçoit 4 fichiers :

  • le fichier original tel qu’envoyé ;

  • ..._corrigé_<année>_T<trimestre>.txt : le fichier nettoyé, à transmettre au comptable pour l’import EBP ;

  • ..._lignes_supprimees_...txt : le détail des livraisons retirées (traçabilité) ;

  • ..._analyse_...txt : les totaux avant/après retrait.

  1. Points d’attention

  • Si un dossier existait déjà pour ce trimestre, son contenu précédent est supprimé et remplacé par le nouveau résultat — pas d’accumulation de versions successives.

  • Nécessite une connexion Google Drive fonctionnelle ; le traitement échoue si elle n’est pas disponible au moment du clic.

  • La règle de retrait (vendredi + samedi + dimanche) est identique à celle appliquée par le module de facturation V2 lors de la création d’une campagne — les deux écrans traitent chacun leur propre fichier, sans lien entre eux.
