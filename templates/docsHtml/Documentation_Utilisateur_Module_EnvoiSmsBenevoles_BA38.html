Aide – Envoi de SMS bénévoles

Cet écran permet d'envoyer un SMS groupé à des bénévoles, en choisissant les destinataires par fonction, par type de bénévole, ou en cochant directement dans la liste.

Filtrer les destinataires

En haut de la page, cocher une ou plusieurs fonctions et/ou un ou plusieurs types de bénévole limite la liste proposée en dessous aux bénévoles correspondants. Seuls les bénévoles ayant un numéro de téléphone portable enregistré sont proposés. Sans aucun filtre, tous les bénévoles avec téléphone sont affichés.

Choisir les destinataires

Dans la liste « Destinataires », cocher chaque bénévole à qui envoyer le SMS, ou utiliser « Tout sélectionner » pour cocher toute la liste affichée par les filtres.

Rédiger le message

Utiliser un texte pré-enregistré : sélectionner un modèle dans la liste remplit automatiquement le message. Le texte reste ensuite modifiable avant l'envoi. Les textes eux-mêmes se gèrent via le bouton « ⚙️ Gérer les textes pré-enregistrés ».

Le compteur sous le message indique le nombre de caractères et le nombre de SMS que cela représente : au-delà de 160 caractères, le message est envoyé (et facturé) en plusieurs SMS.

Envoyer

Une fois les destinataires et le message prêts, cliquer sur « 📤 Envoyer ». Une confirmation est demandée avant le départ réel des SMS. L'envoi se fait ensuite en arrière-plan (il peut prendre quelques dizaines de secondes pour un grand nombre de destinataires) et la page de suivi affiche l'avancement, puis le résultat détaillé par bénévole (envoyé, erreur, numéro invalide...).

Qui peut envoyer des SMS ?

L'accès à cette page est indépendant du droit sur les Plannings ou les Bénévoles : il faut le droit « SMS Bénévoles » (lecture pour consulter, écriture pour envoyer réellement et gérer les textes pré-enregistrés), attribué par un administrateur.

Crédit SMS épuisé

Si le compte SmsFactor n'a plus de crédit en cours d'envoi, l'envoi s'arrête automatiquement, un bandeau d'alerte apparaît sur cette page et sur la page Planning, et un email est envoyé à l'administrateur. Le bandeau reste affiché jusqu'à ce qu'un administrateur clique sur « Marquer comme résolu » (après avoir rechargé le compte).
