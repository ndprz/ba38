Aide – Comparaison planning VIF / Base association

Cet écran compare, association par association, les données de planification stockées dans la base BA38 (“Base”) avec celles issues des exports du logiciel VIF (“VIF”), afin de repérer et corriger les écarts entre les deux.

Lecture du tableau

Pour chaque champ comparé (jour de passage, menu sec, menu frais, fréquence, nombre de bénéficiaires), deux colonnes sont affichées côte à côte :

  • Base : la valeur actuellement enregistrée dans BA38.

  • VIF : la valeur correspondante trouvée dans les fichiers VIF importés.

Code couleur des lignes

  • Ligne jaune : au moins une différence entre la base et VIF a été détectée pour cette association.

  • Ligne rouge : l’association n’a pas été trouvée dans le planning VIF (colonne Code VIF affichée en badge rouge “✖ Absent”).

Code couleur des cellules

  • Cellule surlignée avec pointillés orange (⚠️) : la valeur Base diffère de la valeur VIF. Cliquer dessus propose d’adopter la valeur VIF (une confirmation est demandée avant application).

  • Cellule surlignée avec pointillés rouges (🗑) : l’association est absente du planning VIF mais une valeur existe encore en Base. Cliquer dessus propose d’effacer cette valeur (confirmation demandée).

  • Colonne “Nom association” : si le nom diffère de celui du VIF, un badge rouge “VIF” apparaît (survoler pour voir le nom VIF) ; cliquer sur la cellule propose d’adopter le nom VIF.

Toute mise à jour déclenchée par un clic est enregistrée immédiatement dans la base BA38.

Ignorer une association

Le bouton “Ignorer” à côté du nom d’une association permet d’exclure définitivement ses différences de planning de la comparaison (utile pour les cas particuliers qui ne doivent pas être resynchronisés). Le bouton devient “✓ Ignoré” ; cliquer à nouveau réactive la comparaison pour cette association. La case “Masquer les ignorées” permet de ne plus afficher du tout ces lignes dans le tableau.

Filtres et recherche

  • Tous / Différences uniquement / Pas de planification VIF : boutons permettant de limiter l’affichage aux lignes concernées.

  • 🔍 Recherche : filtre par code VIF ou nom d’association.

  • Le compteur en bas à droite indique le nombre de lignes affichées sur le total.

📥 Export Excel

Exporte le tableau actuellement affiché (en tenant compte du filtre sélectionné) au format Excel.

📂 Charger fichiers VIF

Ouvre une fenêtre permettant de déposer les deux fichiers d’export VIF (planning_partenaires.txt et planning_par_date.txt) qui alimentent la comparaison. La fenêtre indique la marche à suivre dans le logiciel VIF pour générer chacun des deux fichiers, ainsi que la date du fichier actuellement chargé. Il est possible de ne déposer qu’un seul des deux fichiers ; la page se recharge automatiquement une fois l’envoi terminé.
