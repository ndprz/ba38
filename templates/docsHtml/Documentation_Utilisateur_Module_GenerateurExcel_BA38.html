Aide – Générateur Excel personnalisé

Cet écran permet de composer une extraction Excel sur mesure, en choisissant précisément les colonnes à exporter et les filtres à appliquer, plutôt que d’utiliser une extraction prédéfinie de l’écran “Génération de fichiers”.

Type de données

Choisir “Associations” ou “Bénévoles” dans la liste déroulante en haut de la page : la liste des champs disponibles se met à jour en conséquence.

Colonnes et filtres

Les champs sont regroupés par thème (coordonnées, fonction, vie association, etc.) dans des blocs repliables — cliquer sur le titre d’un groupe pour l’ouvrir ou le fermer.

Pour chaque champ :

  • cocher la case pour l’inclure comme colonne dans le fichier exporté ;

  • cliquer sur le bouton 🔎 pour filtrer sur ce champ, sans forcément l’exporter.

Les deux sont indépendants : on peut par exemple filtrer sur “adhésion_2026 = oui” pour ne garder que les bénévoles à jour de cotisation, sans que cette colonne apparaisse dans le fichier final.

Un compteur “X colonnes sélectionnées” ainsi qu’un badge par groupe (“X col · Y filtre(s)”) permettent de garder une vue d’ensemble, même quand un groupe est replié. Un groupe contenant une colonne cochée ou un filtre actif s’ouvre automatiquement à l’affichage de la page.

Cliquer une seconde fois sur 🔎 désactive et vide le filtre. Le bouton “Tout désélectionner” retire les colonnes cochées mais laisse les filtres actifs intacts.

Filtrer par nom / Mode OU

Le champ “Filtrer par nom” en bas de page limite le résultat aux noms ou prénoms contenant le texte saisi.

La case “Combiner les filtres Oui/Non avec OU” ne s’applique qu’aux filtres de type Oui/Non (par exemple “ramasse_chauffeur” ou “cotisation_2025”) : cochée, un enregistrement correspondant à au moins un de ces filtres est inclus, au lieu de devoir correspondre à tous.

Aperçu et export

  • 👀 Aperçu du résultat affiche les 20 premières lignes correspondant aux critères, avec le nombre total de résultats trouvés, sans télécharger de fichier.

  • 📥 Générer le fichier Excel télécharge directement le fichier complet au format .xlsx.

Profils enregistrés

La sélection de colonnes et de filtres peut être sauvegardée comme profil réutilisable (bouton “⭐ Enregistrer comme profil”), puis rechargée ou supprimée depuis le menu déroulant en haut de la page.
