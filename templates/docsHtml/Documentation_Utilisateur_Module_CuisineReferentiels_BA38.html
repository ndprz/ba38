Aide – Référentiels et paramètres cuisine

Les listes utilisées par le reste du module se règlent ici : recettes, ingrédients proposés en réception, noms des utilisateurs, familles, modes de cuisson, sauteuses, DLC des barquettes.

Version du 29/10/2026.

Référentiel des recettes

La liste des recettes C3ES proposées dans Nouvelle production.

Référentiel des recettes

  • Recherchez une recette par son code ou son nom, ou filtrez-la par famille, sous-famille ou cuisson, directement dans les en-têtes de colonnes.
  • ✏️ modifie une recette, 🗑️ la supprime, ➕ Nouvelle recette en ajoute une.
  • 📤 Export étiqueteuse — DLC 5 jours / DLC 3 jours produit le fichier Excel à charger dans l’étiqueteuse. Les codes recette y sont suivis de -05 ou de -03, selon la DLC voulue.

Fiche d’une recette

Une recette a un nom (obligatoire), un code (à laisser vide s’il n’est pas encore attribué), une famille, deux sous-familles et un type de cuisson. Le mode de cuisson est repris automatiquement quand on crée une production avec cette recette.

Ingrédients carnés

La liste des groupes (Boeuf, Volaille, Poisson…) et des produits proposés dans Nouvelle réception.

Référentiel des ingrédients carnés

  • ➕ Nouvel ingrédient ajoute un produit. Pour le groupe, les groupes existants sont proposés pendant la frappe ; un nom nouveau crée un nouveau groupe. ✏️ modifie un produit.
  • Le code VIF de chaque produit est repris sur le bordereau d’envoi des réceptions à la BAI. Un produit sans code VIF y est signalé « à renseigner ».
  • Export produit la liste en Excel (groupe, produit, code VIF).

Paramètres cuisine

Le bouton ⚙️ Paramètres regroupe les listes de valeurs du module.

Paramètres cuisine

  • DLC des barquettes : nombre de jours ajoutés à la date de production. Le changement ne vaut que pour les productions mises en stock après l’enregistrement : les barquettes déjà en stock gardent leur DLC.
  • Utilisateurs : les noms proposés dans les listes « Votre nom » (réceptions, purges, relevés d’hygiène). Un nom tapé avec « ➕ Nouveau… » s’ajoute ici automatiquement.
  • Famille, Sous-famille 1, Sous-famille 2 : les valeurs utilisées dans le référentiel des recettes.
  • Type / mode de cuisson : Four, Sauteuse, Cuisson de nuit…
  • Sauteuses : la liste proposée au démarrage d’une cuisson en sauteuse ou de nuit.
  • Destinataires « Envoi réceptions à la BAI » : une adresse par ligne.

Pour ajouter une valeur, tapez-la dans « Nouvelle valeur » puis touchez ➕. 🗑️ la retire de la liste.
