Paramétrage du poste utilisateur pour les liens e-mail (mailto)

Afin que les adresses e-mail cliquables dans BA38 ouvrent correctement une fenêtre de rédaction Gmail ou Outlook, chaque utilisateur doit configurer une fois son navigateur et Windows.

1. Vérifier que Google Chrome est le navigateur par défaut

Dans Windows :

Paramètres
→ Applications
→ Applications par défaut
→ Google Chrome
→ Définir par défaut

2. Autoriser Chrome à gérer les liens e-mail

Dans Chrome, ouvrir :

chrome://settings/handlers

Vérifier que l’option suivante est activée :

Les sites peuvent demander à gérer des protocoles

3. Autoriser Gmail à gérer les liens e-mail

Ouvrir Gmail :

https://mail.google.com

Puis :

  • attendre quelques secondes,

  • une petite icône 📧 peut apparaître dans la barre d’adresse Chrome,

  • cliquer dessus,

  • choisir :

Autoriser mail.google.com à ouvrir tous les liens e-mail

4. Vérifier le protocole MAILTO dans Windows

Dans Windows :

Paramètres
→ Applications
→ Applications par défaut
→ Choisir les valeurs par défaut par protocole

Rechercher :

MAILTO

Vérifier que la valeur est :

Google Chrome

ou éventuellement :

Outlook

selon l’outil utilisé.

5. Redémarrer complètement Chrome

IMPORTANT :

Fermer :

  • toutes les fenêtres Chrome,

  • puis relancer Chrome.

6. Test de fonctionnement

Dans BA38 :

  • cliquer sur une adresse e-mail dans la liste des associations.

Le comportement attendu :

  • ouverture automatique d’une nouvelle rédaction Gmail,

  • avec le destinataire déjà renseigné.

Symptômes si le poste n’est pas configuré

Cas 1 — Rien ne se passe

Le protocole MAILTO n’est pas associé.

Cas 2 — Page blanche avec :

mailto:test@gmail.com

Chrome reçoit bien le lien mais Gmail n’est pas autorisé comme gestionnaire de messagerie.

Cas 3 — Outlook s’ouvre au lieu de Gmail

Le protocole MAILTO est associé à Outlook dans Windows.
