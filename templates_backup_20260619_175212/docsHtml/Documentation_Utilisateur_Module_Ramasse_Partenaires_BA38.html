Application BA38 – Distribution
Version de la documentation : 11/05/2026

1. Objectif du module

Le module « Ramasse Partenaires » permet de gérer les collectes de marchandises réalisées auprès des fournisseurs partenaires et redistribuées aux associations.

Le module permet notamment :
- la création de modèles de ramasse,
- la saisie mensuelle des quantités collectées,
- le contrôle des données,
- l’export vers VIF,
- la génération d’exports Excel,
- la consultation de l’historique des ramasses.

2. Principe général de fonctionnement

Le fonctionnement du module repose sur un « mois de travail ». Toutes les saisies, contrôles et exports sont réalisés pour le mois sélectionné.

Le processus standard est le suivant :
1. Définir le mois de travail
2. Créer ou modifier les modèles de ramasse
3. Saisir les quantités collectées
4. Contrôler les totaux
5. Exporter les fichiers VIF
6. Archiver et consulter l’historique

3. Gestion du mois de travail

Le mois de travail est sélectionné depuis la page des modèles de ramasse.

Le mois actif est ensuite utilisé automatiquement dans :
- les saisies,
- les contrôles,
- les exports,
- l’historique.

Exemple :
2026-05 correspond au mois de mai 2026.

4. Gestion des modèles de ramasse

4.1 Liste des modèles

La page « Modèles de ramasse » affiche tous les modèles existants.

Chaque ligne contient :
- le nom du modèle,
- l’association concernée,
- le magasin/fournisseur,
- les actions disponibles.

Action Description
➕ Nouveau modèle Créer un nouveau modèle de ramasse
✏️ Modifier Modifier un modèle existant
🗑️ Supprimer Supprimer un modèle
📝 Saisir Ouvrir la saisie de la ramasse
📄 Dupliquer Créer une copie d’un modèle existant

4.2 Création d’un modèle

Un modèle de ramasse définit la répartition théorique des articles pour un fournisseur et une association.

Informations à renseigner :
- Nom du modèle
- Association
- Fournisseur
- Liste des articles VIF
- Pourcentage de répartition par article

Le total des pourcentages doit obligatoirement être égal à 100 %.

4.3 Gestion des articles

Les lignes du modèle permettent d’ajouter des articles VIF.

Pour chaque ligne :
- sélectionner un article,
- saisir le pourcentage,
- supprimer la ligne si nécessaire.

Le libellé de l’article est chargé automatiquement.

4.4 Duplication d’un modèle

La duplication permet de créer rapidement un nouveau modèle à partir d’un modèle existant.

Les lignes et répartitions sont automatiquement recopiées.

5. Saisie des ramasses

La saisie des ramasses est réalisée à partir d’un modèle.

5.1 Informations affichées

La page de saisie affiche :
- le nom du modèle,
- le fournisseur,
- l’association,
- le mois de travail actif,
- la liste des articles.

5.2 Date de ramasse

Par défaut, la date proposée correspond au dernier jour du mois de travail.

Exemple :
Pour le mois 2026-05, la date proposée sera le 31/05/2026.

5.3 Saisie des quantités

Deux modes de saisie sont possibles :

1. Saisie automatique
- saisir le poids total,
- quitter le champ ou appuyer sur Entrée,
- les quantités sont réparties automatiquement selon les pourcentages du modèle.

2. Saisie manuelle
- modifier directement les quantités par article.

5.4 Mise à jour automatique

Si une ramasse existe déjà pour le même fournisseur, la même association et le même mois,
la saisie précédente est automatiquement rechargée.

L’utilisateur peut alors modifier les valeurs existantes.

6. Contrôle des ramasses

L’écran de contrôle permet de vérifier la cohérence des données avant export.

6.1 Contrôle fournisseurs

Le tableau « Totaux par fournisseur » affiche :
- le fournisseur,
- le code VIF,
- le total des kilogrammes collectés.

6.2 Contrôle associations

Le tableau « Totaux par association » affiche :
- l’association,
- le code VIF,
- le total des kilogrammes distribués.

6.3 Vérification de cohérence

Le système compare automatiquement :
- le total des entrées fournisseurs,
- le total des sorties associations.

Si les deux valeurs sont identiques, le contrôle est validé.

7. Exports VIF

Le module génère automatiquement les fichiers CSV nécessaires à l’import dans VIF.

7.1 Export Réception

Le bouton « Export Réception » génère le fichier « recepba38.csv » dans le dossier téléchargements du PC :

Copier ce fichier et le coller dans le bureau a distance :
Destination : Z:\imprec\ba38

Lancer l’Import VIF dans le menu : RECEPTIONS/RETOURS/Importation de réceptions

utiliser Modèle d’importation : BA38IMP
Fichier : laisser recepba38.csv

Lancer l’import avec la flèche verte

7.2 Export Bons de Livraison

Le bouton « Export Bons de Livraison » génère le fichier « BL_38.CSV » dans téléchargements

Copier le fichier et le coller sur le PC local dans C:\import commandes

Dans le bureau a distance VIF
aller sur PREPA – DISTRIBUTION/ Distribution / Import / Importation de BL

Modèle d’importation à utiliser :
PC_BL38
le nom de fichier est renseigné avec BL_38.csv (ne pas changer)
Lancer l’import avec la flèche verte

7.3 Sécurité anti double export

Le système mémorise les exports déjà réalisés.

Si un export existe déjà pour le mois :
- un message d’avertissement est affiché,
- une confirmation supplémentaire est demandée.

8. Historique des ramasses

L’historique affiche toutes les ramasses enregistrées.

Pour chaque ramasse :
- date,
- fournisseur,
- association,
- total kilogrammes.

Actions disponibles :
- consultation du détail,
- suppression.

9. Export Excel

Le bouton « Export Excel » génère un fichier Excel de contrôle contenant :
- la date de ramasse,
- le fournisseur,
- l’association,
- les articles,
- les quantités.

10. Règles métier importantes

  • Le mois de travail doit être défini avant toute saisie.

  • Les pourcentages d’un modèle doivent totaliser 100 %.

  • Un fournisseur doit posséder un code VIF valide.

  • Une association doit posséder un code VIF valide pour l’export BL.

  • Les exports VIF ne doivent être réalisés qu’après contrôle des données.

11. Conseils d’utilisation

  • Créer un modèle par fournisseur et association.

  • Vérifier les codes VIF avant les exports.

  • Toujours effectuer le contrôle avant export.

  • Utiliser la duplication pour gagner du temps.

  • Ne pas modifier manuellement les fichiers CSV exportés.

13. Support

En cas de problème :
- vérifier le mois de travail,
- vérifier les codes VIF,
- vérifier la cohérence des totaux,
